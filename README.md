# CognifyX — Study Smarter. Prepare with Purpose.

CognifyX is an AI-powered adaptive study planner designed to help college students organize their exam preparation, practice important questions, revise efficiently, and track learning progress in one place.

## 🚀 Live Demo

[Try CognifyX](https://cognifyx-223705207800.asia-southeast1.run.app)

## 🎯 Problem Statement

Students often struggle to manage study schedules, organize learning materials, practice exam-oriented questions, and identify topics that need more attention. CognifyX aims to make exam preparation more organized and accessible through a unified study platform.

## ✨ Key Features

- **Personalized Study Planning:** Organize exam preparation with structured study plans.
- **AI Study Assistant:** Get learning support for study-related tasks.
- **Question Generation:** Practice MCQs and 2-mark, 5-mark, and 10-mark questions.
- **Flashcards:** Revise important concepts efficiently.
- **Syllabus and Topic Tracking:** Keep track of topics and study progress.
- **Progress Analytics:** Review learning progress and preparation status.
- **Focus Timer:** Use focused study sessions to manage study time.
- **Study Material Validation:** Identify potentially incomplete or outdated learning materials where supported by the implemented validation workflow.

## 🛠️ Technology Stack

The project uses a web application stack that includes:

- React
- TypeScript
- Vite
- Node.js
- Gemini AI integration

## 💡 What Makes CognifyX Different?

CognifyX brings study planning, exam-oriented practice, flashcards, topic tracking, and progress monitoring together in a single student-focused platform. Its goal is to help learners prepare with greater structure rather than switching between multiple study tools.

## 🧪 Testing and Validation

The application should be tested with different study materials and user workflows. Document-validation accuracy and false-positive rates should only be reported after running and recording a suitable test set.

## 🔮 Future Improvements
